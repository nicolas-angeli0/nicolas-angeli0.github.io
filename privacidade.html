Política de privacidade

Caderno de oportunidades é um aplicativo de uso pessoal, utilizado apenas pelo seu autor, Nicolas Angeli.

Dados acessados

Com autorização do próprio usuário, o aplicativo usa o escopo gmail.readonly para ler apenas os e-mails de alerta de vagas do LinkedIn. Ele não envia, altera nem apaga e-mails.

Uso dos dados

Dos alertas são extraídos somente dados das vagas (título, empresa, local, modalidade e link). Esses dados são usados exclusivamente para organizar e comparar oportunidades com as preferências do usuário.

Armazenamento e compartilhamento

Os dados ficam armazenados no computador do usuário, e as credenciais são cifradas. Nenhum dado é vendido, compartilhado com terceiros ou usado para publicidade.

O uso e a transferência de informações recebidas das APIs do Google seguem a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

Revogação

O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions.
